Проект по моделированию железнодорожной инфраструктуры, сфокусированный на чистоте архитектуры и использовании современных возможностей языка C#.

### Архитектурные решения:
- **Интерфейсы:** Определение контракта поведения через `ITrain`.
- **Абстрактные классы:** Использование `abstract class Train` для инкапсуляции общей логики (количество мест, цена, номер вагона) и предотвращения создания "пустых" объектов.
- **Полиморфизм:** Метод `Func(ITrain obj)` демонстрирует способность работать с любым типом вагона через общий интерфейс.

### Реализованные сущности:
- **Пассажирские:** СВ, Купе, Плацкарт.
- **Специальные:** Вагон-ресторан.
- **Грузовые:** Товарный вагон с уникальной логикой расчета тоннажа.

### Технологии:** .NET, C#, LINQ (для работы со списками), Strong Typing.
